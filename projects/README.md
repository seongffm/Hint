## 권장 저장소 구조
```text
Hint/
├── README.md                 # 전체 프로젝트 인덱스
├── projects/                 # 프로젝트별 소스
│   └── 프로젝트명/
│       ├── README.md
│       └── ...
├── docs/                     # 공통 문서·설계 자료
├── assets/                   # 공통 이미지·자료
└── .gitignore
```
